# Security policy

## Supported versions

The latest release is supported. rex-run is a single-player terminal game: it
opens no sockets, and the only file it writes is a high score in your
platform's data directory.

## Reporting a vulnerability

Please report security issues privately through GitHub's
[security advisories](https://github.com/Pallavrai/rex-run/security/advisories/new)
rather than a public issue. You can expect a first response within a week.
